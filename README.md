# FxPresser

FxPresser 是一个面向《QQ自由幻想》的 Windows 自动按键工具，按顺序执行启用的 F1～F10。

Windows 32位静态单文件构建参阅 [docs/windows-x86-static-build.md](docs/windows-x86-static-build.md)。重构设计记录参阅 [docs/refactor-design-draft.md](docs/refactor-design-draft.md)。

## 主要功能

- 扫描并选择游戏窗口，保存上次选择的角色。
- 修改游戏窗口标题、切换到游戏窗口。
- 使用右上角订书钉按钮控制游戏窗口置顶。
- 为 F1～F10分别设置启用状态和按键间隔。
- 设置每个完整按键之后的全局间隔。
- 设置 KEYDOWN到KEYUP之间的释放间隔。
- 在运行中实时修改按键启用状态和所有时间参数。
- 使用一个可配置的全局快捷键开始或停止。
- 调试日志只在日志窗口打开期间产生，不写入文件。

## 按键方式

关闭“自动选择”时，可以手动选择：

- 共享消息
- 按键+自动窗口
- 按键+手动窗口

开启“自动选择”时，程序每100ms检查一次当前游戏窗口焦点：

- 游戏有焦点：按键+手动窗口
- 游戏没有焦点：共享消息

界面会显示自动选择得到的当前方式。

## 调度规则

调度线程按照 F1→F10固定顺序循环：

1. 未启用的按键直接跳过。
2. 当前时间距离该键上次执行时间达到单键间隔时，执行一个完整按键。
3. 完整按键执行后等待全局间隔，再继续检查下一个按键。
4. 发送失败不改变调度顺序，失败只在调试日志中以红色显示。

Attach资源跟随当前有效按键方式：切换为“共享消息”时自动Attach，切换为两个键盘方式时自动Detach。打开“开始”只创建调度线程；点击“停止”后不再执行下一个按键，当前完整按键返回后退出调度线程。

## 使用步骤

1. 以管理员身份启动游戏和 FxPresser。
2. 点击“扫描游戏窗口”并选择角色。
3. 设置按键启用状态、单键间隔、全局间隔和释放间隔。
4. 根据需要开启自动选择，或者手动指定按键方式。
5. 点击“开始”或使用全局快捷键。
6. 切换游戏窗口、重新扫描或退出程序时，当前自动运行会先停止。

## 构建与分发

正式构建为 Windows x86静态单EXE，不依赖 Qt或ICU DLL，不使用UPX。程序清单请求管理员权限。
